# Test whether a function was produced by a decorator

Test whether a function was produced by a decorator

## Usage

``` r
is_decorated(f)
```

## Arguments

- f:

  Any object.

## Value

`TRUE` if `f` inherits from `"fmisc_decorated"`, else `FALSE`.
